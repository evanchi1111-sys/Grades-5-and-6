# P2 報告：Content Loader 與反向轉接器

日期：2026-11-05　狀態：本機完成並測試，**尚未推上 GitHub**

## 做了什麼
- 新增 `science/content/loader.js`：只讀 `content/manifest.json` 中 `status: published` 的單元，以 `unitId` 取得單元檔；轉成既有 science 模組使用的執行格式（反向轉接器）。只採用 `reviewStatus = approved` 的項目。
- 自然科模組（知識教室、互動實驗室、老師示範、闖關練習、單元測驗、小幫手、學習成果、錯題分析、家長／老師模式）改為「舊單元（原資料檔）＋已發布單元（載入器）」兩種來源都能讀。
- 單元可自訂流程（`unit.flow`）：沒有知識教室或實驗室的單元（如數學試點）直接是「闖關練習 → 單元測驗 → 學習成果」。
- 題型支援：選擇、是非、填空（點詞語填空）、排序。配對／分類／簡答暫不支援，載入時略過並在單元頁提示數量。
- 3D 冒險島：`adventure/data.js` 讀取 manifest，已發布單元自動出現在對應年級、科目的建築卡片並把該科目標為「互動單元已開放」；不必改 3D 場景程式。
- 未發布、已撤下、狀態為 approved 但未 published 的單元：學生端、3D 島、互動教材首頁、小幫手都不會出現（實測：清單改成 approved 後，首頁卡片消失、單元頁顯示「找不到這個單元」、3D 建築回到「準備中」）。
- 小幫手提示：已審核單元顯示「教材已通過審核（版本）」，舊單元維持「尚待人工審核」。

修改前的檔案備份在 `docs/content-platform/backup-before-P2/`（17 個），複製回原位即可還原。要撤下試點：在管理中心「撤回發布」，或把 `content/manifest.json` 的 `units` 清空。

## 已知限制
- 配對、分類、簡答題在學生端尚未支援（資料庫保留，載入時略過）。
- 沒有 `activityRef` 的實驗不會顯示（互動實驗要先有對應的互動程式）。
- 新年級或新科目需要新的建築，目前只能掛在既有四科、五六年級的建築上。
- 試點沒有知識教室，錯題複習會回到「闖關練習」。
- 已發布單元的來源頁碼只顯示檔名，不開啟原檔。
- 推上 GitHub 後，試點會直接公開在網站上（任何人知道網址都看得到）。若不想公開，推送前先撤回發布。
