# Phase E：小幫手、家長模式、老師模式

## 重要說明（避免誤解）
- **小幫手不是連網的 AI 模型。** 目前沒有後端，所以是「只根據教材資料做檢索與分段提示」的小幫手。它能做提示、解釋、出類似題、找教材段落，但不會「理解」自由問題；找不到就說不確定。
- 已保留**可替換的 AI 服務介面**（`tutor/service.js` 的 `RemoteTutor`）與後端規格（`tutor/BACKEND.md`）。預設 `endpoint: null`，完全不連網。**前端沒有、也不可以有任何 API 金鑰。**
- **家長／老師模式只有這台裝置的資料**：沒有帳號、沒有跨裝置同步、沒有班級管理。
- 進入家長／老師畫面的算式小關卡只是**防誤觸，不是安全機制**。

## 小幫手規則（已實作）
1. 先給提示：提示 1 只說知識點與教材位置；提示 2 引用相關教材段落；提示 3 鼓勵先作答。**未作答不公布答案。**
2. 「為什麼答案是這個？」「用簡單的方法解釋」必須在**作答後**才會回答。
3. 未作答時，所有回應中與正確答案相同的文字一律換成「＿＿」，教材句子若含答案就不顯示。
4. 再出一題類似的（同知識標籤的其他題，不計入學習紀錄）。
5. 只引用本單元教材並標示來源；找不到就說「不確定」，並列出可問的觀念。
6. 單元測驗進行中，小幫手鎖定；交卷後才可使用。
7. 使用次數記錄在 `adv-sci-v1`（只增加欄位，不改舊資料）。

## 家長模式
暱稱切換、單元總覽（已開始／通關／學習時間／小幫手使用）、每單元的測驗成績、完成的實驗、**各知識點表現（熟悉／待加強／不熟／連續答錯）**、建議複習（深層連結回對應教材或實驗）、尚未答對的題目與解析；匯出：下載文字報告、複製、列印／存成 PDF、下載原始紀錄 JSON。

## 老師模式
單元選擇、投影用大字投影片（學習目標、情境、原教材卡片、易錯提醒、互動實驗全尺寸、老師示範、題目講解——答案預設隱藏）、題目範圍（全部／基礎／進階／精熟／課堂小考 12 題＋解答）、🎲 抽一題、字級調整、全螢幕、← → 換頁；列印題目與解答；匯出這台裝置的學習成果。
